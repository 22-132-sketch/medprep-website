Install Help

How to Install

Your phone or PC may show a warning because the app does not come from an app store. That is normal for files you download yourself. Here is exactly what to tap.

Android

Takes about 2 minutes.
1
Tap Download for Android. If your browser says this type of file can harm your device, tap Download anyway (or Keep).
2
When it finishes, tap Open in the download message. You can also open MedPREP-Android.apk from your Downloads folder.
3
If your phone says it is not allowed to install unknown apps, tap Settings, switch on Allow from this source, then press Back.
4
Tap Install, then Open, and sign in with Google.
If Google Play Protect asks about an unrecognised app, tap More details, then Install anyway.

Windows

Takes about 3 minutes.
1
Click Download for Windows. If your browser asks, choose Keep.
2
Open MedPREP-Windows-Setup.exe from your Downloads.
3
A blue box may say “Windows protected your PC”. This is Windows SmartScreen, and it shows for new apps. Click More info, then Run anyway.
4
Follow the installer, then open MedPREP from the Start menu and sign in.
Already have an older MedPREP for Windows? Install this new one once by hand. After that, the app will tell you when an update is ready.
Safety

Where Do These Files Come From?

The app files are built automatically from MedPREP’s own code and published only on our public release page: github.com/22-132-sketch/medprep-releases. Please download only from this page or that one. The question banks and notes are not inside the app file; they download after you sign in and your plan is checked. If you like, compare the SHA-256 code under each download with the file you received. If they match, the file is exactly ours.

Questions

Before You Install

Is this safe? It’s not on the Play Store or App Store.
The app files come only from MedPREP’s own public release page, built from our code, and each one has a checksum you can compare. Your phone or PC warns about any file from outside the stores, so the steps above show what to tap. The browser version runs inside your browser’s normal security sandbox, like any website.
Do I need to register before installing?
You can install the app first, but full question banks unlock after registration (PKR 1,699/session, down from PKR 2,500). Register here.
Will it take up storage on my phone?
The browser version uses very little. The app keeps your offline study content on your device, so the space it takes depends on what you download. You can see and manage it inside the app.
What if the install button doesn't show up?
The download did not start, or the browser version’s install button is missing? Try Chrome (Android/Windows) or Safari (iPhone), or message us on WhatsApp and we'll walk you through it.
Do I need Premium to use the app?
Anyone can install it. Offline study needs a Premium plan. Message us on WhatsApp first, or register here.
Is there an app for iPhone, Mac or Linux?
Not yet. On those, use the browser version.
